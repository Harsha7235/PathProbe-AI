# PathProbe-AI

AI-Based Discovery and Characterization of Network-Path Protocol Interference

## Project

PathProbe-AI is a research-oriented Computer Networks project that uses
controlled active probing to study how network paths and intermediate
middleboxes treat different types of traffic.

- Ubuntu/WSL2 setup
- ns-3.48 setup
- Baseline network experiment
